# playwright-automation-kra
Playwright JavaScript automation framework for KRA

# Tata 1mg Playwright Automation


## Project
Tata 1mg UI automation using Playwright and JavaScript.

## Prerequisites
- Node.js
- npm
- Playwright

## Installation
npm install

## Run Tests
npx playwright test

## Run in headed mode
npx playwright test --headed

## View Report
npx playwright show-report
